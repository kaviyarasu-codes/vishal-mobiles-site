# Vishal Mobiles — one-QR social page

<img src="screenshot.webp" alt="Vishal Mobiles page on a phone" width="260">

A **mobile-only** landing page for a phone shop. One QR code on the shop counter opens every link: Instagram, Facebook, WhatsApp channel, Google reviews, Google Maps and YouTube.
